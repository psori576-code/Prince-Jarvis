---
name: Prince Jarvis scope
description: Product direction for the first mobile release and deferred capabilities.
---

The first Prince Jarvis mobile release is intentionally local-first: a single chat screen, local placeholder replies, persistent chat history, and on-device voice recording. Live AI, speech-to-text, notes, reminders, and internet search are deferred follow-up capabilities.

**Why:** The user explicitly chose to keep the initial Android build simple and continue without external AI integration.

**How to apply:** Do not add provider-dependent behavior or extra assistant modules unless the user selects the follow-up work.
